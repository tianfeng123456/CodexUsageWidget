# 本轮验证报告

本报告用于记录 Windows 11 本机 Release 交付版本的验证状态。被测应用为 WPF / .NET 8 / SQLite 桌面程序，发布目标是 `win-x64` 自包含单文件：

```text
dist\CodexUsageWidget.exe
```

本文记录已完成的 Vision Glass 构建、自动化测试、中英文、双待机样式、UI、
三主题、两种基础待机静默和周额度预热后静默验收；真实日志查询计时仍保留较早
哈希候选作为趋势参考。机器报告中的结果只对各自记录的 EXE SHA-256 有效。

## 已实现口径

- 待机态提供默认 80×80 圆环与可选 208×80 胶囊；两者悬停后都原子切换为
  420×540，不经过 420×80 或其他短暂中间窗口尺寸。待机组件是固定锚点，面板
  根据工作区向右、向左、向下或向上展开。
- 收起态圆环底部的心电波是进度轨道的一部分：未到达时使用轨道色，进度经过底部时按路径长度逐段点亮，状态点同步沿波形移动。
- 胶囊状态按界面显示的整数百分比动态派生：70% 及以上为“额度充足”，
  30%～69% 为“用量平稳”，10%～29% 为“额度偏低”，1%～9% 为“即将用尽”，
  0% 为“已用尽”；无实时数据时显示“正在同步”或“等待数据”。状态文字与波形
  共用绿 / 黄 / 橙 / 红状态色，圆环进度也复用同一判定策略。计算只响应已有额度
  与读取状态变化，不增加计时器、日志读取、数据库操作或轮询。
- 胶囊不再使用会越过圆角遮罩的 `DropShadowEffect`；桌面快照与玻璃底色由独立
  圆角背景层承载，208×80 透明窗口角落不再出现方形包边或矩形阴影伪影。
- 浅色与深色主题分别为胶囊提供专属高对比文字和状态色；展开面板的次级、弱文字
  也按明暗主题调整，底部四个汇总值使用正常字重，在动态桌面背景上仍保持清晰的
  信息层级。
- 鼠标移出后只等待一个 UI 调度回合复核状态，目标黑盒收起耗时为 0～150 毫秒；固定、拖动或关闭自动收起时不执行。
- 每个周期最多显示前 9 个真实任务；任务数超过 9 时，第 10 行是无任务明细的“其他”。总计按输入和输出计算，缓存输入与推理输出不重复计数。
- 近 7 日是当前时刻向前精确滚动的 168 小时，不是七个自然日。
- Token 数值使用自然中文单位，按“完整整数 / 万 / 亿 / 万亿”分段，最多两位小数。
- 悬停展开切回今日并只刷新今日；每次标签点击（包括重复点击当前标签）刷新目标周期；手动刷新更新当前周期和额度。
- 收起态没有固定 30 秒轮询，不周期性刷新排行或写入 SQLite。日志 watcher 只登记变化路径，额度尾读采用静默约 1.5 秒、连续写入最多约 3 秒的事件合并。
- 首次无历史索引时执行一次单线程后台索引；已有索引启动时不预加载四个周期。
- 主题提供 System / Light / Dark，System 通过 Windows 事件同步，不进行主题轮询。
- 外观设置提供 0～100 的玻璃透明度：数值越高，玻璃背景越透明；文字、图标和
  状态色不随该值淡出。拖动时即时预览，取消设置恢复打开设置前的数值，保存后
  持久化；变化只重绘玻璃表面，不触发日志读取、周期统计、SQLite 刷新或后台轮询。
- 界面语言提供 System / 简体中文 / English；System 对任意 `zh-*` 使用简体中文，
  其余区域使用 English。切换语言只替换内存资源，不触发日志、统计或数据库刷新。
- 界面只保留一套玻璃材质，不再提供皮肤选择器；System / Light / Dark 只改变同一界面的明暗主题。
- Vision Glass 不启用 Windows 原生 Acrylic。窗口只在加载、收起/展开、主题或
  DPI 变化、拖动结束和手动刷新等事件发生时抓取一次桌面背景，软件模糊在后台
  线程完成并冻结为静态图像；不持续抓屏、不持续模糊，也没有渲染循环。快照只
  填充 80×80 圆环、208×80 胶囊或 420×540 圆角面板，外侧没有矩形玻璃底或
  装饰边框。
- 每日周额度仅统计 `limit_id=codex` 且 `window_minutes=10080` 的服务端直接观测值；每天取最后一次直接观测，相邻日仅显示净变化，不再称为“当日新增”。七天数据只在用户点击全局顶部唯一入口时查询，并在主窗口内部 Overlay 展示。
- 设置窗口逻辑尺寸为 460×590；分组按“外观 → 常驻行为 → 数据来源 → 维护”
  排列，主题、语言、待机样式和玻璃透明度位于最前面的外观分组。旧
  `AutoCollapseDelayMs` 仅为配置兼容保留，运行时忽略。
- 托盘与 EXE 使用同一套原创空心三环线稿图标，不复用第三方品牌标识；ICO 内置
  多种尺寸，供文件管理器、任务栏、托盘和高 DPI 场景选择合适清晰度。

查询结果需同时确认：

- 四个周期的 `前 9 + 其他 = 总计`，并逐字段核对输入、缓存输入、缓存写入、输出和推理输出。

- 某日没有直接观测时明确显示无数据；相邻日净变化可能因周窗口重置为负，不能解释为当日实际新增消耗。

## 隐私边界

应用只读 `sessions`、`archived_sessions` 和 `session_index.jsonl` 中统计所需字段，不读取 `auth.json`、密码、访问令牌、用户提示词或聊天正文，也不联网上传数据。索引保存在：

```text
%LocalAppData%\CodexUsageWidget\usage-index-<home-hash>.db
```

## 结论与限制

Vision Glass 界面已完成 16/16 真实鼠标 UI、圆环/胶囊双待机样式、
System / Light / Dark 三主题、中英文双向切换和单 HWND 周额度 Overlay 验收。
实现口径已统一为单皮肤、事件触发的一次性桌面快照与后台软件模糊。全部最终机器
报告对应同一个 A2FB25… 哈希。该哈希已完成 197/197 自动化测试、Release 构建、
自包含单文件发布，以及圆环、胶囊和周额度预热后三个不少于 65 秒的静默样本；
三个性能样本正式观察期均未观察到 SQLite 写入。除真实日志查询计时仍属于较早
数据集的趋势参考外，构建、UI、主题、本地化与低资源主验收均已收敛到同一发布
哈希。

统计边界仍需注意：

- 累计数据只覆盖本机已保存或已经索引的日志。
- 剩余额度依赖本地日志中的 `rate_limits`，缺失时只能显示未知。
- watcher 漏事件时额度可能短暂滞后，由启动、恢复、悬停展开或手动刷新校准，不恢复固定轮询。
- Codex 本地日志格式未来可能变化，解析器届时可能需要适配。
